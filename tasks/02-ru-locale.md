# 02. Русская локаль интерфейса, по умолчанию

## Зачем

NzrAiWiki должен открываться на русском у любого нового посетителя. Сейчас локали
`ru` нет, по умолчанию стоит `en` (`web/i18n/config.ts`).

Форк продолжает подтягивать апстрим, где регулярно появляются новые ключи и даже
новые файлы в `en/`. Ни отсутствующий в `ru` ключ, ни отсутствующий файл не должны
ронять страницу или показывать голый ключ: вместо них подставляется английское
значение, а скрипт проверки их находит.

## Где работать

Основное дерево `C:\Users\Nazar\Работа\OpenDeepWiki`, ветка `nzr/rebrand-ru`.
Параллельно в том же дереве задача 03 создаёт `web/i18n/messages/ru/admin.json`.
Задача 01 идёт в отдельном worktree. `node_modules` в `web/` уже установлены.

## Что сделать

1. **`web/i18n/config.ts`:**
   - добавить `"ru"` в `uiLocales`;
   - добавить `ru: "Русский"` в `uiLocaleNames`;
   - `defaultUiLocale = "ru"`;
   - `defaultWikiLanguage` и `wikiLanguageCodes` не трогать.
2. **Резерв на английский.**
   - Создать `web/i18n/merge-messages.ts` без импортов next-intl с функцией
     `deepMerge(base, override)`. Она возвращает новый объект: значения из `override`
     поверх `base`, рекурсивно по вложенным объектам. Если `override` равен
     `undefined` или `{}`, результат — копия `base`. Массивов в словарях нет.
   - В `web/i18n/request.ts`, в `loadMessages`:
     - для любой локали, кроме `en`, каждый namespace собирать как
       `deepMerge(en[ns], locale[ns])`;
     - **импорт файла локали, кроме `en`, не должен бросать при отсутствии файла.**
       Обернуть так, чтобы отсутствующий файл давал `undefined`, и тогда namespace
       целиком берётся из `en`. Это обязательно: пока задача 03 не сдана,
       `ru/admin.json` нет, а сайт с `defaultUiLocale = "ru"` уже должен работать.
       То же случится при каждом новом файле в апстримном `en/`.
   - Поведение для `en` не меняется.
3. **Переводы.** Создать `web/i18n/messages/ru/*.json` — перевод всех файлов из
   `en/`, **кроме `admin.json`** (его делает задача 03, файл не создавать и не трогать).
   - Структура и порядок ключей как в `en`, переводятся только значения.
   - Плейсхолдеры `{name}`, `{count}` и т.п. сохранить буква в букву.
   - ICU-плюрал обязателен там, где в `en` стоит число плюс существительное и значение
     приходит числом. Пример: `{count, plural, one {# файл} few {# файла} many {# файлов} other {# файла}}`.
     Если неясно, приходит ли число, оставить обычный `{count}`.
   - Кавычки в тексте только «ёлочки». Одинарную `'` не ставить: в ICU она экранирует
     `{`, `}` и `#`.
   - Переводы строк `\n` внутри значений сохранять.
   - Название продукта — **NzrAiWiki** (не OpenDeepWiki и не DeepWiki), даже если в
     `en` пока стоит старое. Исключение — примеры имён и путей репозиториев
     (`Example: OpenDeepWiki`): их оставить.
   - `common.announcement.*` перевести как есть, баннер выключает задача 01.
   - Тон: интерфейсный русский, на «вы», короткие кнопки («Сохранить», «Отмена»).
     Без канцелярита.
   - Глоссарий:

     | en | ru |
     |---|---|
     | repository | репозиторий |
     | wiki | вики |
     | catalog / table of contents | оглавление |
     | branch | ветка |
     | provider | провайдер |
     | model | модель |
     | token | токен |
     | prompt | промпт |
     | mind map | карта связей |
     | bookmark | закладка |
     | subscribe | подписаться |
     | MCP, API, URL, OAuth, GitHub | не переводить |
4. **Две захардкоженные копии локалей.** Чинить их разрешено и нужно, иначе на дефолтном
   пути вылезет не тот язык.
   - `web/app/global-error.tsx`: добавить `"ru"` в `UI_LOCALES`, сделать
     `DEFAULT_LOCALE = "ru"`, добавить блок `ru: { title, description, back }`.
   - `web/components/repo/markdown-renderer.tsx`:
     - добавить в `repoMarkdownText` блок `ru` с переводом всех ключей блока `en`;
     - в выборе `locale` в `MarkdownRenderer` (строки ~462–468) добавить ветку
       `language === "ru" ? "ru"`;
     - финальное `: "zh"` не трогать.
5. **Скрипт проверки.** `web/scripts/check-i18n.js` уже существует (апстримный, сверяет
   ключи всех локалей) — **не трогать**. Написать отдельный
   `web/scripts/check-i18n-ru.mjs` (Node, без зависимостей), который сравнивает `en` и
   `ru` и печатает:
   - отсутствующие в `ru` файлы;
   - отсутствующие и лишние ключи;
   - ключи, у которых множество переменных расходится. Для ICU-плюрала переменной
     считается имя до первой запятой;
   - дубликаты ключей в сыром тексте `ru/*.json`.

   Код выхода 1, если что-то нашлось. В `web/package.json` добавить
   `"i18n:check-ru": "node scripts/check-i18n-ru.mjs"`.
6. **Тесты (vitest).**
   - `web/i18n/__tests__/config.test.ts`: `defaultUiLocale === "ru"`,
     `isUiLocale("ru")`, `resolveUiLocaleFromWikiLanguage("ru") === "ru"`.
   - `web/i18n/__tests__/merge-messages.test.ts`: прочитать с диска **реальные**
     `en/common.json` и `ru/common.json`, удалить из копии `ru` один вложенный ключ,
     слить и проверить, что на его месте английское значение, а соседний ключ
     остался русским. Отдельно проверить, что `deepMerge(en, undefined)` равен `en`.

## Чего не делать

- `web/middleware.ts` не трогать. Приоритет там `?lang=` > cookie > дефолт,
  `Accept-Language` не читается, так что смены дефолта достаточно.
- `web/i18n/messages/ru/admin.json` не трогать (задача 03).
- Файлы задачи 01 не трогать: `web/app/sidebar.tsx`, `web/lib/*`,
  `with-announcement.tsx`, `auth/page.tsx`, `chat-panel.tsx`, словари других локалей,
  LICENSE, README.
- Остальные захардкоженные строки в компонентах не переводить, это отдельная задача.
- Известные мелочи оставить как есть: селект языка в `app/(main)/settings/page.tsx`
  (он сохраняет настройку, а не переключает UI), `inLanguage` в JSON-LD документов,
  `Intl.NumberFormat("en")` в админке.
