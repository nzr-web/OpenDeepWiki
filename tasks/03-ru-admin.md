# 03. Перевод админки: `web/i18n/messages/ru/admin.json`

## Зачем

Часть русской локали NzrAiWiki (см. `tasks/02-ru-locale.md`, делается параллельно).
`en/admin.json` — самый большой словарь, ~58 КБ, поэтому вынесен в отдельную задачу.

## Что сделать

Создать `web/i18n/messages/ru/admin.json` — перевод `web/i18n/messages/en/admin.json`.

- Структура ключей точно как в `en`, порядок тот же, переводятся только значения.
  Не пропускать ни одного ключа.
- Плейсхолдеры `{name}`, `{count}` и т.п. сохранить буква в букву. Где есть число, можно
  ICU-плюрал `{count, plural, one {# репозиторий} few {# репозитория} many {# репозиториев} other {# репозитория}}`.
- Название продукта — **NzrAiWiki**. Если в `en` встречается OpenDeepWiki / DeepWiki
  как имя продукта, в `ru` писать NzrAiWiki. Исключение — примеры путей и имён
  репозиториев: их оставить как есть.
- Технические значения не переводить: URL, имена переменных окружения, JSON-примеры,
  имена моделей и провайдеров, HTTP-заголовки, плейсхолдеры вроде `sk-...`.
- Тон: интерфейсный русский, на «вы», короткие подписи кнопок и колонок. Без канцелярита.
- Глоссарий (общий с задачей 02):

  | en | ru |
  |---|---|
  | repository | репозиторий |
  | wiki | вики |
  | catalog | оглавление |
  | branch | ветка |
  | provider | провайдер |
  | model | модель |
  | token | токен |
  | prompt | промпт |
  | mind map | карта связей |
  | role / permission | роль / право |
  | department | отдел |
  | task routing | маршрутизация задач |
  | MCP, API, URL, OAuth, GitHub, Webhook | не переводить |

## Чего не делать

Не трогать никакие файлы, кроме `web/i18n/messages/ru/admin.json`.

## Ворота (выполнить и привести вывод в отчёте)

- `node -e` или маленький временный скрипт вне репозитория, который сравнивает
  множества ключей `en/admin.json` и `ru/admin.json`: должно быть 0 отсутствующих
  и 0 лишних.
- Тот же скрипт: для каждого ключа множество `{переменных}` в `ru` должно совпадать
  с `en`. Для ICU-плюрала считается имя переменной до запятой.
- Файл — валидный JSON в UTF-8 без BOM.
- В отчёте привести 10 случайных пар «en → ru» для выборочной проверки.

Коммитить не надо.
