# 03. Перевод админки: `web/i18n/messages/ru/admin.json`

## Зачем

Часть русской локали NzrAiWiki (см. `tasks/02-ru-locale.md`, делается параллельно в
том же дереве). `en/admin.json` — самый большой словарь, ~58 КБ, поэтому вынесен
отдельно.

## Что сделать

Создать `web/i18n/messages/ru/admin.json` — перевод `web/i18n/messages/en/admin.json`.

- Структура и порядок ключей как в `en`, переводятся только значения. Ни одного
  ключа не пропускать.
- Плейсхолдеры `{name}`, `{count}` и т.п. сохранить буква в букву.
- ICU-плюрал обязателен там, где в `en` число плюс существительное. Пример:
  `{count, plural, one {# репозиторий} few {# репозитория} many {# репозиториев} other {# репозитория}}`.
  Если неясно, что в переменной число, оставить обычный `{count}`.
- Кавычки в тексте только «ёлочки». Одинарную `'` не ставить: в ICU она экранирует
  `{`, `}`, `#`. В `en` есть строки с `'About' > 'App ID'` (~869–898), их передать
  через «».
- Переводы строк `\n` внутри значений (например, ~879) сохранить.
- Название продукта — **NzrAiWiki**. Если в `en` OpenDeepWiki / DeepWiki стоит как имя
  продукта («your DeepWiki admin URL»), писать NzrAiWiki. Примеры имён
  (`my-deepwiki-app`) оставить.
- Не переводить: URL, имена переменных окружения, JSON-примеры, имена моделей и
  провайдеров, HTTP-заголовки, плейсхолдеры вроде `sk-...`.
- Тон: интерфейсный русский, на «вы», короткие подписи кнопок и колонок. Без канцелярита.
- Глоссарий (общий с задачей 02):

  | en | ru |
  |---|---|
  | repository | репозиторий |
  | wiki | вики |
  | catalog | оглавление |
  | branch | ветка |
  | provider | провайдер |
  | model | модель |
  | token | токен |
  | prompt | промпт |
  | mind map | карта связей |
  | role / permission | роль / право |
  | department | отдел |
  | task routing | маршрутизация задач |
  | MCP, API, URL, OAuth, GitHub, Webhook | не переводить |

## Чего не делать

Не трогать никакие файлы, кроме `web/i18n/messages/ru/admin.json`. Задача 02 в это
время правит остальной `web/i18n/` в том же дереве.

## Ворота (выполнить и привести вывод в отчёте)

- Если `web/scripts/check-i18n-ru.mjs` из задачи 02 уже существует, запустить его:
  находок по `admin` быть не должно.
- Независимо от этого временный скрипт **вне репозитория** (в `%TEMP%`) должен
  показать:
  - `Object.keys` на каждом уровне вложенности совпадают с `en` поэлементно,
    включая порядок;
  - у каждого ключа множество `{переменных}` в `ru` совпадает с `en`
    (у ICU-плюрала это имя до первой запятой);
  - в сыром тексте файла нет повторяющихся ключей на одном уровне;
  - в значениях нет одинарной `'`.
- Файл — валидный JSON в UTF-8 без BOM.
- В отчёт: 10 случайных пар «en → ru» и все строки, где использован ICU-плюрал.

Коммитить не надо.
